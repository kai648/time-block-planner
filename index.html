THINK BEFORE YOU BLOCK
Consult this page each morning before filling the day's first PLAN column.

THE METHOD

  1. Plan. Each morning, give every minute a job in the first column — tap the grid to drop a block, drag its lower edge to size it.
  2. Revise. When reality knocks you off schedule, don't patch — re-plan the rest of the day in the next column.
  3. Capture. Mid-block tasks and ideas go to the right page so you can return to focus instead of switching.
  4. Shut down. Mark your metrics, glance at tomorrow, check the box. The day is closed.
